# 법정선임관리 시스템

<p align="center"><strong>에이스종합관리(주)</strong></p>

관리 대상 건물별로 소방·전기·기계·가스 등 **법정 선임 자격자**의 선임일·선임기간·교육 기한을 관리하고,

- **🏢 본사 관리자**: 전체 사업소의 선임 현황을 한 화면에서 확인, 임박/만료 항목 필터링
- **📋 사업소 보고**: 사업소별 담당자가 자신의 현황을 입력하고, 본사로 보낼 보고서를 인쇄/내보내기

### 데이터는 어떻게 저장되나요?

이 페이지는 GitHub Pages 정적 사이트이기 때문에 별도의 서버·데이터베이스가 없습니다. 따라서:

- 입력한 데이터는 **현재 사용 중인 브라우저에만** 저장됩니다(다른 PC·휴대폰과 자동으로 동기화되지 않습니다).
- 사업소는 **[사업소 보고] → [본사로 보낼 파일 내보내기(JSON)]** 로 현황 파일을 만들어 이메일/메신저로 본사에 전달합니다.
- 본사는 전달받은 파일을 **[본사 관리자] → [사업소 데이터 가져오기]** 로 불러와 전체 현황에 반영합니다.
- 처음 열면 안내용 **샘플 사업소(예시)** 데이터가 보이며, 실제 데이터 입력 전 삭제하거나 이름을 바꿔 사용하세요.
- 실제 인원 정보 등 민감한 데이터는 이 저장소(공개 GitHub 저장소)에는 올라가지 않으며, 어디까지나 사용자 브라우저와 내보낸 파일 안에만 존재합니다.

향후 여러 사업소가 실시간으로 함께 입력·조회해야 한다면(예: Google Sheets 연동, 로그인 기능 등) 별도 백엔드 연동이 필요합니다.
