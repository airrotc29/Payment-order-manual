# 블루오션 레지던스 호텔 입주지원센터 관리 프로그램

㈜블루오션자산관리 입주지원센터장 업무용 관리 프로그램입니다. 서버나 데이터베이스 없이
**브라우저 안에서만 동작**하는 정적 웹앱(PWA)으로, 스마트폰 홈 화면에 앱처럼 설치할 수도 있습니다.

## 관리 업무 4종

1. **분양형 호텔 계약관리** — 호실별 위탁운영/임대차 계약, 계약기간, 만료 D-day 자동 표시
2. **장기 숙박객 입퇴실관리** — 입실/퇴실 예정일, 재실 현황, 퇴실 연체 자동 표시
3. **입주지원 업무 및 민원 응대** — 민원 접수부터 처리완료까지, 3일 이상 미처리 자동 강조
4. **하자 요청접수 및 관리** — 하자 접수·처리 현황, 긴급 건·5일 이상 지연 자동 강조

각 업무는 대시보드에서 한눈에 요약되고, 개별 화면에서 검색·상태별 필터·등록·수정·삭제·
CSV 내보내기가 가능합니다.

## 사용 방법

### 그냥 열어보기 (설치 없이)
`index.html` 파일을 더블클릭해서 브라우저로 열면 바로 사용할 수 있습니다.

### GitHub Pages로 배포하기 (추천)
1. 이 폴더 전체를 `Blue-Ocean-Property` 저장소 루트에 업로드합니다.
   (GitHub 저장소 페이지 → **Add file → Upload files** → 폴더 안 파일 전체를 드래그)
2. 저장소 **Settings → Pages** 에서 Branch를 `main` / `/(root)` 로 설정 후 저장합니다.
3. 몇 분 뒤 `https://airrotc29.github.io/Blue-Ocean-Property/` 로 접속하면 됩니다.
4. 스마트폰에서 그 주소로 접속 후 "홈 화면에 추가"를 하면 앱처럼 설치됩니다.

## 데이터 저장 방식 (중요)

- 모든 데이터는 **이 브라우저(이 기기)에만** 저장됩니다(localStorage). 서버로 전송되지 않으며,
  외부에서 접근할 수 없습니다.
- 기기를 바꾸거나 브라우저 데이터/방문기록을 지우면 데이터가 사라집니다.
- **설정** 메뉴에서 정기적으로 "백업 파일 다운로드"(JSON)로 백업해 두고, 필요할 때
  "백업 파일 복원"으로 불러올 수 있습니다.
- 다른 직원과 데이터를 함께 쓰려면(동시 접속·공유), 이 방식으로는 불가능합니다 —
  서버/데이터베이스가 있는 버전으로 별도 제작이 필요합니다.

## 로고 넣기

`assets/logo.png` 파일을 넣으면 상단 헤더에 회사 로고가 자동으로 표시됩니다
(파일이 없으면 자동으로 🏨 아이콘으로 대체됩니다).

## 폴더 구조

```
index.html          메인 페이지
css/style.css        디자인
js/utils.js          공통 유틸(날짜 계산, CSV 등)
js/store.js           localStorage 저장소
js/modules.js         4개 업무 모듈 항목/필드 정의
js/crud.js            공통 등록/수정/삭제/검색 화면
js/dashboard.js       대시보드 요약 화면
js/app.js             라우팅, 설정(백업/복원/초기화), 초기화
manifest.webmanifest  PWA 설정
sw.js                 오프라인 캐시(서비스워커)
icons/                앱 아이콘
assets/               로고 등 이미지 (logo.png를 넣으세요)
```
